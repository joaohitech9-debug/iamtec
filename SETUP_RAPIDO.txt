⚡ SETUP RÁPIDO - FORMULÁRIO DE CONTATO

O que você precisa fazer:

1. Acesse: https://www.web3forms.com
2. Clique "Get Started Free" (registre gratuito)
3. Clique "+ New Form"
4. Dê um nome e selecione email de destino: raphael@iamtec.com.br
5. COPIE a Access Key que aparecer
6. Crie arquivo .env na raiz do projeto com:

   VITE_WEB3FORMS_ACCESS_KEY=cole_aqui

7. Reinicie: npm run dev
8. Pronto! Teste o formulário

Tudo pronto em ~2 minutos!

Para instruções detalhadas: Ver CONFIG_CONTACT_FORM.md
